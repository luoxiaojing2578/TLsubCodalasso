# TLsubCodalasso

R Code for the proposed Trans-subCodaLasso method.

The code is for the model implementation, simulation studies, and real data analysis in the paper and supplementary material:

**Transfer Learning for High-Dimensional Regression with Compositional Covariates: Application to Microbiome Studies**

The simulation and real data analysis scripts are provided in the corresponding folders. Each folder contains a `README.md` file with specific instructions.
